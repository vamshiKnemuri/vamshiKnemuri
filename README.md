# DevOps, Platform Engineering & Agentic AI

I build secure cloud platforms and evidence-grounded AI workflows. My work focuses on AWS, Kubernetes, Terraform, GitOps, CI/CD, and the controls that make automated decisions reviewable.

## Featured projects

- **[SentinelOps AI](https://github.com/vamshiKnemuri/sentinelops-ai-platform)** — Human-governed Kubernetes incident response with runbook retrieval, bounded read-only MCP tools, policy checks, approval, and auditability.
- **[Response Lab](https://github.com/vamshiKnemuri/foundry-supply-chain-response-lab)** — A local supply-chain response simulator using linked operational records, evidence-backed proposals, policy gates, human approval, and a Foundry-oriented integration blueprint.

## Engineering focus

- **DevOps and platform engineering:** AWS, EKS, Kubernetes, Terraform, GitOps, observability, and secure delivery pipelines.
- **Agentic AI:** grounded tool use, structured decisions, deterministic validation, human-in-the-loop actions, and evaluation.
- **Responsible demos:** reproducible local workflows and clear boundaries between implemented features and proposed integrations.

Response Lab runs locally on synthetic data; its Palantir Foundry integration has not been tested in a tenant.
